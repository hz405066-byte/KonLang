 КОНЦЕПЦИЯ ЯЗЫКА
=================
· Расширение файлов скриптов: .kn
· Основной принцип: Максимальная простота, базовое построение вывода.
· Правило синтаксиса:Команда и её аргументы записываются слитно, без пробелов и знаков препинания между ними. Структурные блоки выделяются фигурными скобками  {}, а обращения к данным — квадратными []. 

 1. СИСТЕМНЫЕ УКАЗАТЕЛИ И ДАННЫЕ
=================================
X — это способ дать название функции, контейнеру и т. д. Перед именем функций и контейнеров и всему, чему можно дать название, ставится подчёркивание. (К примеру, kon_plus, мы используем X как название контейнеру.)

Язык использует динамические регистры (контейнеры) для хранения данных:
· [kon_X] — Контейнеры кода или текста (заполняются через kon).
· [inp_X] — Переменные пользовательского ввода (заполняются через input).
· [rand_X] — Переменные случайного выбора (заполняются через random).
· [key_X] — Клавиши (заполняются через key).
· Переменные общего назначения задаются через команду set.
· Для добавления множества команд, которые сделают работу с кодом более удобной и разнообразной, служит команда inp[имя_библиотеки]. Это обычный способ импорта библиотеки. В системе также имеются встроенные библиотеки, такие как style_text.

 2. Полный список комманд
==========================

 2.1. Основные комманды языка
------------------------------
· kon_X{Код} — Объявить контейнер. Может хранить исполняемый код в котором могут находиться данные (регистр [kon_X]).

· print{"текст"} — Вывести текст.
· print{x,y,"текст"} — Вывести текст на указаных координатах.
· print{{"текст"*10}} — Вывести текст 10 раз подряд.

· input_X{"текст"} — Запросить у пользователя ввод текста с выводом подсказки (Промпта). Результат пишется в [inp_X].
· input_X{int"текст"} — Запросить у пользователя ввод текста с выводом подсказки (Промпта) и запрашивая тип данных (Подробнее в '3. Необязательная информация'). Результат пишется в [inp_X].
· input_X{"текст",5} — Запросить у пользователя ввод текста с выводом подсказки (Промпта) и ограничить количество символов ввода. Результат пишется в [inp_X].

· key_X — Считать одну клавишу в [key_X] (без Enter).Обычные символы: "a", "1", "!".Спецклавиши: "up", "down", "left", "right", "enter", "esc", "tab", "space", "backspace", "del", "home", "end", "pgup", "pgdn", "f1".."f12". Комбинации: "ctrl+c", "alt+x", "shift+tab".

· clear — Стереть всесь текст и интерфейс с экрана.

· random_X{A,B,C} — Случайно выбрать один из элементов в фигурных скобках и записать в переменную [rand_X].

· set{a=5} — Присвоить переменной 'a' значение '5'.
· set{a={A,B,C}} — Присвоить переменной 'a' список.
· len[x] — Длина строки или списка.

· math{a+b} — Выполнить математически действий. Можно использовать типы данных. (int если целое, иначе float)
· math{int a+b} — вычислить, вернуть целое.
· math{float a+b} — вычислить, вернуть float.
· math{double a+b} — вычислить, вернуть double.

· start:exec[kon_X] - Выгружает контейнер.
· exec[kon_X] — Выполнить содержимое регистра/контейнера как код. Если содержимое не является валидным блоком кода → программа завершается с ошибкой.

· cycle{...} — Конструкция бесконечного цикла. Если указано число (например, cycle5{...}, цикл выполнится 5 раз), Если число не указано (cycle), цикл выполняется бесконечно, для выхода из бесконечного и обычного цикла используется sc.
· if[]{} eli[]{} els{} — Проверка условия. В квадратных скобках пишется условие, а в фигурных скобках код .Поддерживает операторы: ==, !=, >, <, >=, <=. Если условие истинно, выполняется следующая за ним команда или блок цикла.
· and, or — Логические операторы для связывания нескольких условий в input или if.
· def_X[]{} – функция.
· ret[x] — возврат значения из функции (без него def бессмыслен).
· ret — выйти из текущего kon_X/def_X без возврата.

· openFile{путь} — чтение файла.
· writeFile{путь,данные} — создание файла и запись данных в него.
· appendFile{путь,данные} — запись и дозапись в файл.
· searchFile{путь} — поиск файлов этой папке.
· delFile{путь} – Удалить файл.

· timeX — Задержка выполнения. Расчёт: 100 единиц = 1 секунда.

· cexit — Немедленно завершить работу программы.

· * Коментарий *  — Коментарий.

 2.2. Экран
------------
· scr_size — → [scr_w], [scr_h] (раздрешение экрана).
· scr_cur — → [cur_x], [cur_y] (позиция курсора).

· scr_bg{цвет} — фон экрана.
· scr_beep{частота} — звуковой сигнал с заданой частатой колебаний.

 3. Необязательная информация
==============================
Цвета (Colors):
• BLACK — Черный
• RED — Красный
• GREEN — Зеленый
• YELLOW — Желтый
• BLUE — Синий
• MAGENTA — Пурпурный
• CYAN — Голубой
• WHITE — Белый
• GRAY — Серый

Стили шрифта (Font Styles):
• BOLD — Жирный
• DIM — Тусклый / Бледный
• ITALIC — Курсив
• UNDERLINE — Подчеркнутый
• BLINK — Мигающий
• REVERSE — Инверсия (фон ↔ текст)
• STRIKE — Зачеркнутый

Основные типы данных:
Тип     Описание
int     Целые числа
double  Вещественные числа (двойная точность)
float   Вещественные (одинарная точность)
char    Один символ
